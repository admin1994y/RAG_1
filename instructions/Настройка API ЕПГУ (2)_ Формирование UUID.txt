<p><span style="font-family:Calibri, sans-serif"><span style="font-size:16px"><strong>Формирование UUID сотрудникам</strong></span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>UUID (Universally Unique Identifier)</strong> — это уникальный цифровой ключ доступа, который получает каждый сотрудник после оформления электронной доверенности на ЕПГУ. Этот идентификатор является обязательным для авторизации и работы через API системы.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">После того как администратору предоставлены соответствующие полномочия, он может выдавать UUID другим сотрудникам. Для этого необходимо добавить его в группу доступа «Технологический портал ЕПГУ».</span></span></p>
