<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Система поддерживает <strong>автоформирование для всех типов обращений</strong>, однако <strong>пользователь</strong> самостоятельно <strong>определяет список</strong> автоматизированных процессов. Настройка позволяет <strong>выделить нужные типы обращений для автоматического формирования</strong>, остальные типы остаются в ручном режиме для выборочного применения по необходимости. <strong>Для настройки</strong> списка обращений с автоматическим формированием <strong>необходимо</strong> <strong>обратиться в техническую поддержку</strong>.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Важно!</strong> При обращении в техподдержку настраивается список обращений, формирующихся в автоматическом режиме для всех взыскателей! Также для более тонкой настройки доступно полное отключение/включение автоформирования отдельно для каждого взыскателя.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Порядок действий:</strong></span></span></p>
<ol>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Перейти в раздел <strong>«Реестры» → «Взыскатели»</strong>.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Выбрать нужного взыскателя, нажав на строку с его названием.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В карточке взыскателя найти параметр <strong>«Автоформирование обращений»</strong>.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Чтобы изменить значение, нажать на текущий статус в этом поле.</span></span></li>
</ol>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>«Да»</strong> — система будет <strong>автоматически формировать</strong> все <strong>обращения</strong>, для которых пользователь <strong>настроил автоформирование</strong> через службу технической поддержки</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>«Нет»</strong> — <strong>все обращения</strong> для этого взыскателя нужно будет создавать <strong>вручную</strong>, автоформирование отключено.</span></span></li>
</ul>
