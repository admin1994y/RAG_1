<h1>Подача заявлений в суд: порядок действий (краткая памятка)</h1>
<h2>Шаг 1. Заполните реестр для досудебной стадии</h2>
<ul>
<li>Выполните заполнение по шаблону — ** На этом этапе не добавляйте новые столбцы**.</li>
</ul>
<p>{7f0d4269-d90b-4db8-b1f9-2eb8da385af2} Инструкция: <code>e650919b160384d1b8efb7ed600cb33e53f6b534</code></p>
<p>{30fe63be-84db-4761-a87a-8cbfda3a0880} <strong>Цель:</strong> подготовить корректный реестр без отклонений от шаблона.</p>
<hr/>
<h2>Шаг 2. Загрузите реестр в досудебную стадию</h2>
<ul>
<li>Загрузите файл в систему.</li>
<li>Проверьте, что статус реестра изменился на <strong>«Выполнено»</strong>.</li>
<li>Убедитесь, что должники появились в разделе <strong>«Досудебная стадия»</strong>.</li>
</ul>
<p>{f6f77fa5-ceb8-4315-a6f1-b8f289ef473d} Инструкция: <code>eac50bc282ffc196ea7f4457a07d9e16432cbcdc</code></p>
<p>{300541ee-2f24-4ebe-8a62-4a17adc4bec0} <strong>Цель:</strong> подтвердить успешную загрузку и появление должников в системе.</p>
<hr/>
<h2>Шаг 3. Добавьте необходимые типы документов в реестр</h2>
<p>Если в реестре нет нужных типов документов:</p>
<ol>
<li>Перейдите в раздел <strong>«Реестры / Типы документов»</strong>.</li>
<li>Проверьте наличие нужного типа документа. Если его нет — создайте через <strong>«Действия → Добавить»</strong>.</li>
<li>Добавьте все необходимые типы документов.</li>
<li>В исходный реестр (которым загружали должников) добавьте столбцы, соответствующие новым типам документов.</li>
<li>Заполните эти столбцы именами файлов.</li>
<li>Загрузите реестр на обновление данных.</li>
<li>Дождитесь статуса <strong>«Выполнено»</strong>.</li>
</ol>
<p>{e6a7eb6c-0e51-4eda-b7dd-9f8b5377dd41} Инструкция: <code>64c87b77457a87555f18c24242bb6a684c555660</code></p>
<p>(раздел «Добавление пользовательского типа документа»)</p>
<p>{4b9150f0-13d7-427c-9a85-1b2f7e42cbb2} <strong>Цель:</strong> обеспечить соответствие реестра требуемым типам документов и корректно обновить данные.</p>
<hr/>
<h2>Шаг 4. Добавьте необходимые данные в реестр</h2>
<p>Если в реестре нет всех данных, которые используются в шаблоне заявления:</p>
<ul>
<li>Добавьте в исходный реестр столбцы, соответствующие созданным в шаблоне пользовательским тегам.</li>
<li>Заполните эти столбцы соответствующей информацией.</li>
<li>Сохраните реестр и загрузите его на обновление данных.</li>
<li>Дождитесь статуса <strong>«Выполнено»</strong>.</li>
</ul>
<p>{43271550-5e77-4e0d-aa04-f028e54b9c4e} Инструкция:</p>
<pre>
<code>64c87b77457a87555f18c24242bb6a684c555660</code></pre>
<p>(раздел «Связь пользовательских тегов с реестром»)</p>
<p>{cb110a42-1d7d-4f14-b315-967df98aec35} <strong>Цель:</strong> обеспечить полноту данных в реестре для корректного формирования заявлений по шаблону.</p>
<hr/>
<h2>Шаг 5. Измените подстадию при необходимости</h2>
<ul>
<li>По умолчанию всем долгам присваивается подстадия <strong>«Уведомить должника»</strong>.</li>
<li>Если эта подстадия неактуальна, выделите строки с долгами.</li>
<li>Нажмите <strong>«Действия → Изменить стадию»</strong>.</li>
<li>Выберите в списке: <strong>«Досудебная стадия_Загрузить кредитное досье»</strong>.</li>
</ul>
<p>{7e380216-1915-4ebd-8fc5-71516a63314e} <strong>Цель:</strong> назначить корректную подстадию в соответствии с текущей работой по долгу.</p>
<hr/>
<h2>Шаг 6. Загрузите архив с документами</h2>
<ul>
<li>Подготовьте и загрузите архив с необходимыми документами.</li>
<li>Инструкция:
	<pre>
<code>34af3362709a15a5b1e963fb83988f81a2e6ccdb</code></pre>
</li>
</ul>
<p>{0d87f1c9-cf15-4ddc-8883-1eb7bdb0f780} <strong>Цель:</strong> прикрепить и загрузить комплект документов по долгам.</p>

<h2>Шаг 7. Сформируйте заявление на вынесение судебного приказа</h2>
<ul>
<li>Сформируйте заявление для отправки должнику.</li>
<li>Инструкция:
	<pre>
<code>a05dc338f96b9d05e63db011a6d653d21a2849b4</code></pre>
</li>
</ul>
<p>{cb40756f-6bbc-4ff8-8977-b9c0c908aece} <strong>Цель:</strong> подготовить заявление, которое будет направлено должнику.</p>
<hr/>
<h2>Шаг 8. Отправьте заявления должнику</h2>
<p>Перейдите в раздел <strong>«Обращения / Заявления / Подготовленные заявления»</strong> и выберите способ отправки:</p>
<ul>
<li><strong>API ЭЗП</strong> — если подключено API Почты России.</li>
<li><strong>Отправить Почтой</strong> — если подключено API Почты России.</li>
<li><strong>Нарочная отправка</strong> — если API Почты России отсутствует.</li>
</ul>
<p>⚠️ <strong>При нарочной отправке:</strong> после передачи обращений на Почту заполните реестр по отправленным заявлениям (с ШПИ) и загрузите его на обновление данных.</p>
<p>{b09542e8-35ed-4538-8728-c0e0fb6374a6} <strong>Цель:</strong> зафиксировать отправку заявлений должнику выбранным способом и актуализировать данные в системе.</p>
<hr/>
<h2>Шаг 9. Дождитесь автоматического формирования заявлений в суд</h2>
<p>Заявления в суд формируются системой автоматически при выполнении условий:</p>
<ul>
<li>Отправлена копия заявления на вынесение судебного приказа должнику.</li>
<li>Оплачена госпошлина.</li>
</ul>
<p>{dc191d0d-56d3-41d7-9410-83ce0956ee5c} <strong>Цель:</strong> убедиться, что система автоматически подготовила заявления в суд.</p>
<hr/>

<li>Отправьте заявления в суд выбранным способом.</li>
<li>Инструкция:
	<pre>

</li>
</ul>

<li>Долг будет находиться в судебной стадии до момента вынесения судебного приказа.</li>
