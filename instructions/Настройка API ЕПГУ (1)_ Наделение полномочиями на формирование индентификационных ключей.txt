<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Для того чтобы сотрудники организации могли отправлять обращения в ФССП, каждому из них необходим уникальный идентификатор (UUID). Формировать и выдавать эти ключи может <strong>руководитель</strong> или <strong>уполномоченный им сотрудник</strong>.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Первый шаг — предоставить ответственному сотруднику доступ к инструменту выдачи UUID, добавив его в группу доступа «Технологический портал» ЕПГУ.</span></span></p>
<p> </p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Порядок действий</strong></span></span></p>
<ol>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Авторизуйтесь в личном кабинете организации</strong> на Едином портале госуслуг (ЕПГУ).</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В профиле организации выберите раздел <strong>«Группы доступа»</strong>.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Нажмите на строку <strong>«Единая система идентификации и аутентификации»</strong>.</span></span></li>
</ol>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{a0906440-0590-495f-9957-75c09e920881}</span></span></p>
<ol start="4">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В открывшемся блоке найдите <strong>«Технологический портал» и</strong> нажмите кнопку <strong>«Присоединить нового сотрудника»</strong>.</span></span></li>
</ol>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{ec60c970-eef8-4388-b04d-d95a151fd2bb}</span></span></p>
<ol start="5">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Начните вводить <strong>фамилию</strong> сотрудника в поле поиска. Когда система предложит варианты, выберите нужного сотрудника из <strong>выпадающего списка</strong>.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Нажмите кнопку <strong>«Добавить»</strong>.</span></span></li>
</ol>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{5ce53497-9a6b-4da2-a99d-5d1e119363c5}</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">После этого необходимо создать доверенность для сотрудника, ответственного за формирование уникальных идентификаторов (UUID) для остальных пользователей.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Порядок предоставления полномочий</strong></span></span></p>
<p> </p>
<ol>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Авторизуйтесь в <strong>личном кабинете организации</strong> на Едином портале госуслуг (ЕПГУ).</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Перейдите в раздел <strong>«Профиль организации»</strong>.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В боковом меню выберите <strong>«Доверенности и доступы»</strong>.</span></span></li>
</ol>
<p style="margin-left:24px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{da4be958-1ecf-4af5-9cfc-436ccf8eea74}</span></span></p>
<p style="margin-left:28px"> </p>
<ol start="4">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">На открывшейся странице в блоке <strong>«</strong>Группы доступа<strong>» </strong>проверьте, чтобы сотрудник был добавлен в группу доступа<strong> «Администраторы. </strong></span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Выберите блок <strong>«Доверенности»</strong>.</span></span></li>
</ol>
<p style="margin-left:24px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{29b7b63e-0004-4425-a18f-eb128ea52c77}</span></span></p>
<p> </p>
<ol start="5">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Нажмите кнопку <strong>«Создать доверенность»</strong>.</span></span></li>
</ol>
<p style="margin-left:24px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{21e42b55-a991-4e81-83c1-3d2e143de6a8}</span></span></p>
<p style="margin-left:28px"> </p>
<ol start="6">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В форме создания выберите опцию <strong>«Сотруднику»</strong>.</span></span></li>
</ol>
<p style="margin-left:24px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{ba5918ae-94ba-44ec-8b64-8131e3abdc4d}</span></span></p>
<p> </p>
<ol start="7">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Заполните обязательные поля:</span></span></li>
</ol>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>ФИО сотрудника:</strong> выберите из выпадающего списка.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Номер доверенности:</strong> укажите произвольный номер (можно использовать цифры, буквы, символы).</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Срок действия:</strong> установите период, на который выдаются полномочия.</span></span></li>
</ul>
<ol start="8">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Нажмите кнопку <strong>«Продолжить»</strong>.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В открывшемся окне с категориями полномочий найдите и разверните раздел <strong>«Прочее»</strong>.</span></span></li>
</ol>
<p style="margin-left:24px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{8b32bccf-6746-42fc-bd7c-774611b44d41}</span></span></p>
<p> </p>
<ol start="10">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"> В списке найдите и отметьте <strong>полномочие</strong>: <strong>«Формирование API Key для доступа к API Госуслуг ИС TECHLEGAL»</strong>. </span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Нажмите кнопку <strong>«Продолжить»</strong>.</span></span></li>
</ol>
<p style="margin-left:24px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{2ccc7455-126d-4a75-96c2-f1ba7f61b157}</span></span></p>
<p> </p>
<ol start="12">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"> Проверьте список предоставляемых полномочий, нажмите «Продолжить».</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Если вы администратор:</strong> передайте созданную доверенность на подпись руководителю организации. </span></span></li>
</ol>
<p style="margin-left:28px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Если вы руководитель:</strong> подпишите доверенность с помощью своей <strong>Усиленной Квалифицированной Электронной Подписи (УКЭП)</strong>.</span></span></p>
<p style="margin-left:-19px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">{f9493df2-1f08-469c-af40-3f493c282740}</span></span></p>
<p> </p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Важно!</strong> Только сотрудники с данным полномочием могут создавать UUID. Обычным пользователям, которым нужен UUID только для отправки обращений, эта доверенность <strong>не требуется</strong>.</span></span></p>
