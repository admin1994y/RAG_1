<h1>Настройка API Sber.</h1>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Для активации возможности оплаты государственной пошлины через сервис «Сбер API» необходимо предварительно настроить подключение к системе «СберБанк Бизнес Онлайн».</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Порядок настройки:</strong></span></span></p>
<ol>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В основном меню перейти в раздел <strong>«Реестры»</strong> → <strong>«Взыскатели»</strong>. </span></span><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Выбрать из списка нужного взыскателя и открыть его карточку.</span></span></li>
</ol>
<p>{2982fa23-b120-48e3-895b-ce305f5bdaa7}</p>
<ol start="2">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В карточке взыскателя нажать на виджет <strong>«API СБЕР БИЗНЕС»</strong>.</span></span></li>
</ol>
<p>{da54d29a-8c0f-4aec-b381-ae5d8f550974}</p>
<ol start="3">
<li>В открывшейся форме заполнить все поля.</li>
</ol>
<ul>
<li style="list-style-type:none">
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Client ID;</strong></span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Client Secret</strong>;</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Дата окончания Client Secret</strong>;</span></span></li>

Для корректной работы необходимо вставить в это поле следующий текст:  </span></span></li>

</ul>

<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Важно!</strong> Произойдет переход на страницу авторизации «СберБанк Бизнес Онлайн». Необходимо выполнить вход в личный кабинет для подтверждения предоставления доступа к данным.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">При успешном завершении процесса авторизации в карточке настроек в поле <strong>«Вход в систему»</strong> будет отображаться статус: <strong>«Вход в систему выполнен»</strong>.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">При необходимости предусмотрена возможность выхода из системы.</span></span></p>

<h2><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Настройка счета для списания госпошлины</strong></span></span></h2>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">После успешной настройки интеграции с "СберБанк Бизнес Онлайн" в карточке взыскателя в виджете <strong>«API СБЕР – Банковские счета»</strong> будет отображен полный список расчетных счетов компании.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Порядок назначения основного счета для оплаты:</strong></span></span></p>
<ol>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В карточке взыскателя нажать на виджет <strong>«</strong><strong>API Сбер – Банковские счета»;</strong></span></span></li>
</ol>
<p>{3c50dcde-3a13-4fca-a5af-2785e8d807b0}</p>
<ol start="2">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В списке доступных счетов найти расчетный счет, с которого планируется производить оплату госпошлин.</span></span></li>
</ol>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Если в строке выбранного счета в столбце <strong>«Основной»</strong> по умолчанию указано значение <strong>«Да»</strong> - значит счет установлен в качестве источника оплаты автоматически.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Если в строке выбранного счета в столбце <strong>«Основной»</strong> по умолчанию указано значение <strong>«Нет»</strong> - нажать на значение <strong>«Нет»</strong>. Статус автоматически изменится на <strong>«Да»</strong>.</span></span></li>
</ul>
<p>{dff732f5-690f-46c0-aa95-ae2a99d1c514}</p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">После выполнения данной настройки при подтверждении оплаты госпошлины через сервис «Сбер API» денежные средства будут списываться <strong>только с этого выбранного основного счета</strong>.</span></span></p>
