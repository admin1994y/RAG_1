<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>1. Что такое Госпочта и для чего она нужна</strong></span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Госпочта — это раздел в АИС Техлегал, в который собираются документы (постановления, уведомления и т.д.), направленные судебными приставами в адрес взыскателя через личный кабинет ЕПГУ.</span></span></p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">В этом разделе отображаются постановления по тем Постановления фиксируются только по ИП, которые загружены в систему.</span></span></p>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Сами документы после обработки попадают в виджет Документы внутри соответствующей карточки должника.</span></span></li>
</ul>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>2. Как документы попадают в Госпочту (сбор)</strong></span></span></p>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Инструмент:</strong> для получения документов необходимо запускать <strong>плагин</strong>.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Периодичность:</strong> рекомендуется запускать плагин для сбора госпочты <strong>раз в три дня</strong>.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Объем:</strong> при запуске плагин собирает все документы, поступившие с момента его последнего запуска.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Пример:</strong> если плагин не запускали полгода, то после запуска загрузятся все документы за этот период.</span></span></li>
</ul>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>3. Работа с документами в разделе Госпочта</strong></span></span></p>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Неразобранные письма:</strong> все вновь поступившие документы попадают в ветку меню «<strong>Госпочта» – «Неразобранные письма»</strong>.</span></span></li>
</ul>
<p><span style="font-size:12pt"><span style='font-family:"Times New Roman",serif'>{84cb5d5c-28df-403e-94f7-66e8216ce95f}</span></span></p>
<p style="margin-left:48px"> </p>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Ознакомление и архив:</strong> чтобы документ появился в карточке должника, с ним нужно ознакомиться. Для этого пользователь должен разобрать письма: прочитать их и затем отправить в архив.</span></span>
<ol>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Выделите нужное письмо.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Нажмите «Действия» → «В архив».</span></span></li>
</ol>
</li>
</ul>
<p><span style="font-size:12pt"><span style='font-family:"Times New Roman",serif'>{820351b8-7d56-453d-b9c7-f4f6fca0a144}</span></span></p>
<ol>
<li style="list-style-type:none">
<ol start="3">
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">После переноса в архив, постановление отобразится в виджете «Документы» внутри соответствующего КД. </span></span></li>
</ol>
</li>
</ol>
<p style="margin-left:48px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong><span style="color:#ee0000">Важно!</span></strong> Без выполнения этого действия документ в карточке должника не появится.</span></span></p>
<p> </p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>4. Отображение документов в карточке должника (КД)</strong></span></span></p>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">После разбора госпочты и отправки в архив, документы становятся доступны внутри КД.</span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Путь:</strong> перейти в нужный КД → открыть виджет «<strong>Документы»</strong>.</span></span></li>
</ul>
<p><span style="font-size:12pt"><span style='font-family:"Times New Roman",serif'>{1e7eee23-bd51-425d-99f9-64367a79557d}</span></span></p>
<p style="margin-left:48px"><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif">Здесь можно найти все постановления, полученные от ФССП по должнику.</span></span></p>
<p> </p>
<p> </p>
<p><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>5. Правила видимости Госпочты для пользователей</strong></span></span></p>
<ul>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Администратор</strong> видит всю корреспонденцию по всем КД. </span></span></li>
<li><span style="font-size:12pt"><span style="font-family:Calibri,sans-serif"><strong>Остальные пользователи</strong> видят в Госпочте только те документы, которые относятся к активным КД, где они являются ответственными.</span></span></li>
</ul>
